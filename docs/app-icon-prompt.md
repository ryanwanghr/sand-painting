# Sand Painting app icon

Generated with the built-in imagegen tool. The original is retained in Codex's
generated-images directory. Project and store PNGs are resized exports of the
same artwork, with no transparency or pre-rounded corners.

- Master/Unity icon: `Assets/Art/Branding/SandPaintingIcon.png` (1024 × 1024).
- Google Play icon: `docs/store-assets/sand-painting-icon-512.png` (512 × 512,
  RGBA PNG with every pixel opaque).

Assigned as the default Unity app icon and in all six Android adaptive icon
slots. Existing Android build artifacts predate this artwork; rebuild them to
include the new launcher icon. iOS will inherit the default icon when its build
support is installed and the project is built there.
